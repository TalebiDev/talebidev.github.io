# TalebiDev — Portfolio

Personal portfolio site for Mohammad Talebi (DevOps Engineer).

## Structure

```
├── index.html          # Markup
├── css/
│   └── style.css       # All styles
├── js/
│   └── script.js        # All interactive behavior (terminal, forms, translation, etc.)
├── images/
│   ├── profile.webp         # Profile photo
│   ├── favicon.ico          # Multi-res fallback icon (16/32/48)
│   ├── favicon-32x32.png    # Browser tab icon
│   ├── favicon-192x192.png  # Google search result icon / Android
│   └── apple-touch-icon.png # iOS "Add to Home Screen" icon
```

## Usage

Just open `index.html` in a browser, or serve the folder with any static file host (GitHub Pages, Netlify, Vercel, etc.). No build step required.

> Note: Google pulls the search-result icon from your site's favicon, but it can take days to weeks to re-crawl and update — it won't change instantly after deploying.
